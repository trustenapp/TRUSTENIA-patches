# Contributing to TRUSTENIA Δ Patches

Vielen Dank für dein Interesse, zu **TRUSTENIA Δ Patches** beizutragen!

## Fehler melden / Report Bugs
Nutze bitte unsere vorgefertigten [GitHub Issue Templates](https://github.com) und gib immer die verwendete App-Version (z. B. YouTube `v21.30.216`) an.

## Code beitragen / Pull Requests
1. Forke das Repository.
2. Erstelle einen neuen Feature-Branch (`git checkout -b feature/mein-patch`).
3. Teste deinen Build lokal mit `./gradlew :patches:build`.
4. Öffne einen Pull Request mit einer kurzen Beschreibung deiner Änderung.
